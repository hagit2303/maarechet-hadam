# מערכת הדם · יחידת לימוד

קישור לתלמידים: https://hagit2303.github.io/maarechet-hadam/

יחידת לימוד מקוונת בביולוגיה לכיתה י' (מערכת ההובלה). מתבססת על חומרי מט"ח ומורחבת בחומרים נוספים.

- שיעור 1: גילוי מחזור הדם
- שיעור 2: המחזור הגדול והמחזור הקטן
- שיעור 3: ויסות זרימת הדם לרקמות
- שיעור 4: מבנה הלב
- שיעור 5: מעבדת ניתוח לב חזיר
- שיעור 6: תפוקת הלב (מצגת, הדמיית מזרק ובלון, סימולציה, דף עבודה — נבנו עם Tab)
- שיעור 7: כלי הדם — מבנה, לחץ דם ומהירות זרימה (מצגת, סימולציה, תרגיל, משימת "בונים יחידת לימוד")
